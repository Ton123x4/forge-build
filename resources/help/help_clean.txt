Usage: forge clean [package] [options]

Description:
    Removes build artifacts for the workspace. Without a profile flag,
    removes the entire forge directory (artifacts, cache, modules and logs).
    With --debug, --preview or --release, removes only the build and output
    directories for that profile.

Options:
  --debug                   Clean debug mode artifacts only
  --preview                 Clean preview mode artifacts only
  --release                 Clean release mode artifacts only
  --project <dir>           Specify the workspace directory

Examples:
  forge clean
  forge clean --release
  forge clean --project ./myworkspace
